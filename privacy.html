Privacy Policy

Koen's Clips Uploader · last updated 18 November 2026

This app is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

What it accesses

With the owner's permission, the app uses the YouTube Data API to upload videos and set their titles, descriptions and publish times, and the YouTube Analytics API to read the channel's own statistics.

What it stores

The Google sign-in token is stored only on the owner's own computer. The app does not collect, store, share or sell data about anyone else, and it does not use cookies or tracking.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
